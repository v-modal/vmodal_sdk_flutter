TenantCredentialSource

TenantCredentialSource class

Shared tenant renewal coordinator, independent of app-user lifetimes.

One normal renewal is shared by all providers. A superseding renewal or external install fences older results using both ticket and base revision. No key is persisted, and failures block calls unless the host explicitly permits retaining the previous credential under its validity policy.
